【共通の狙い】
・既存の剣・盾・コイン・敵スプライトに合わせた、濃厚なダークファンタジー・アニメ調
・64x64 でも判別できる太いシルエット
・UI側でレアリティ枠を描くため、画像自体に枠・文字・背景は入れない
・光源は左上、3/4ビュー、中央配置、余白10%
・背景は完全透過。透過非対応モデルは末尾の「透過処理」を参照

【共通ネガティブプロンプト】
background, scenery, landscape, floor, ground, cast shadow, drop shadow,
reflection, checkerboard, transparency grid, text, letters, numbers,
readable runes, logo, watermark, signature, UI frame, rectangular border,
multiple objects, duplicate, cropped, cut off, blurry, low resolution,
jpeg artifacts, photorealistic, 3D render, plastic toy, flat vector icon,
messy composition

【透過処理】
1. 透過対応モデル（GPT-image-1 API の background="transparent" など）
   そのまま PNG で出力する。
2. ChatGPT / Gemini / DALL-E など
   「背景を完全に透明にした PNG で出力して」と追加指示する。
   チェッカー柄が描き込まれた場合は 3. へ。
3. 透過非対応モデル
   各プロンプト末尾の
   "isolated on transparent background, alpha channel PNG"
   を
   "isolated on a flat solid magenta background (#FF00FF), no shadow"
   に置換して生成し、rembg / Photoshop / GIMP で背景を削除する。
   ※白背景は聖光・氷・水レリックの白い発光と溶けるため避ける。
   ※被写体にマゼンタが含まれる場合は、被写体にない色（緑 #00FF00 など）を使う。
4. 背景除去用の追加プロンプト
   "Remove the background completely and return a PNG with a transparent
   background. Preserve the relic's edges, glow, and fine details.
   Do not add shadows or a new background."
5. 保存は JPEG ではなく PNG-24（アルファ付き）。
   生成後に余白をトリムし、256x256 または 512x512 に縮小する。
